## eng git

Manage multiple git repositories

### Synopsis

This command is used to facilitate the management of multiple git repositories in your development folder.

```
eng git [flags]
```

### Options

```
  -c, --current   Use current working directory instead of configured development path
  -h, --help      help for git
  -i, --info      Show current git repository management configuration
```

### Options inherited from parent commands

```
      --config string   config file (default is $HOME/.eng.yaml)
  -v, --verbose         verbose output
```
