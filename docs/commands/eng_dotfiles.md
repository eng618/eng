## eng dotfiles

Manage dotfiles

### Synopsis

This command is used to facilitate the management of private hidden dot files.

```
eng dotfiles [flags]
```

### Options

```
  -h, --help   help for dotfiles
  -i, --info   Show current dotfiles configuration
```
