## eng asdf status

Display an overview dashboard of installed asdf plugins, active versions, and disk usage

### Synopsis

Provides a high-level summary dashboard of all managed asdf plugins, installed version counts, active pinned versions, and total disk space used.

```
eng asdf status [flags]
```
